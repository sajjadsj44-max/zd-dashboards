Calculation settings

Defaults applied to new analyses and to every generated mix.
House standard build-up. A Material → B Wastage (on material only) → C Labour → D Plant → E Access / cradle → F Transport → subtotal → G Overheads → H Profit → rate per unit. Dry-volume factor 1.54 for concrete, 1.30 for mortar; 50 kg cement bag = 1.250 cft.

Data safety

Everything lives in this browser only. Nothing is uploaded anywhere.
Back up regularly. Clearing browser data, switching device or using a private window will lose the rate library. Export the JSON backup after any significant editing session.
Hard reset. Wipes every item, rate, BOQ line and setting stored in this browser and rebuilds the library from the seeded defaults. This cannot be undone.

Import items from CSV

Column headers are matched automatically. Rows with problems are listed rather than silently dropped.
Expected columns (any order, case-insensitive): Category, Sub-category, Description, Specification, Unit, Material Rate, Labour Rate, Plant Rate, Wastage %, Overhead %, Profit %. Any missing numeric column is read as zero and the item is flagged unrated.
